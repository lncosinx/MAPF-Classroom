MAPF 课堂 · 使用说明（Windows 绿色版）
==========================================

不用安装，解压就能用。需要 Windows 10 或 11（64 位）。

一、第一次使用
------------------------------------------
1. 把整个压缩包解压到【不含中文和空格】的文件夹，例如 D:\MAPF-Classroom
   （放在"桌面""下载"这类路径里，如果你的 Windows 用户名是中文，AI 模型可能加载失败）
2. 双击 start_classroom.bat
   · 会弹出一个黑色窗口，等几秒钟加载 AI 模型
   · 加载好以后，浏览器会自动打开老师页（http://localhost:8000/teacher）
3. 第一次运行时 Windows 会弹出防火墙提示：请勾选「专用网络」，点「允许访问」
   · 如果点错了（点了取消），或者学生连不上：右键 allow_firewall.bat，选「以管理员身份运行」，
     它会自动放行；如果它提示当前是「公用网络」，在学校网络里可以选 y 一起放行
4. 黑色窗口里会显示「学生加入地址」，老师页右上角也有地址和二维码。
   学生用手机或电脑的浏览器扫码，或者输入这个地址，就能加入

二、上课
------------------------------------------
· 学生和老师电脑要连在【同一个 WiFi / 局域网】里
· 老师页上选地图、设置规则，点「开始」
· 黑色窗口不要关：关掉它，课堂就结束了
· 下课后直接关掉黑色窗口即可

三、学生连不上怎么办
------------------------------------------
1. 确认学生和老师电脑在同一个网络（不要一个连 WiFi、一个用手机流量）
2. 有些 WiFi 是「访客网络」，设备之间互相隔离，换成普通的 WiFi
3. 右键 allow_firewall.bat →「以管理员身份运行」，再试一次
4. 黑色窗口里如果写着"本机还有这些地址"，说明电脑有好几块网卡（比如装了虚拟机）。
   换成和学生同一个网的那个地址：在 start_classroom.bat 所在的文件夹空白处，按住 Shift 点右键，
   选「在此处打开 PowerShell 窗口」，输入
       .\start_classroom.bat --ip 192.168.1.23
   （把 192.168.1.23 换成那个地址）
5. 杀毒软件拦截时，把这个文件夹加入信任

四、其他常见问题
------------------------------------------
· 提示「8000 端口已被占用」：可能已经开着一个课堂窗口，先关掉它；或者像上面那样打开 PowerShell，输入 .\start_classroom.bat --port 8001 换个端口
  （这时学生地址里的 8000 也会变成 8001；防火墙是按程序放行的，换端口不用重新放行）
· 电脑比较慢、每步要等很久：老师页「规则」里的「AI 模型」换成「轻量 2.16M（老电脑）」
· 黑色窗口闪一下就没了 / 出现报错：拍下窗口内容，联系维护的老师

五、数据和隐私
------------------------------------------
· 课堂记录保存在 app\data 文件夹里（每节课一个文件），只有昵称和座位号，没有真实姓名
· 导出的 CSV / JSONL 含学生的作答记录，请妥善保管，不要随意转发
· 换电脑时，把 app\data 文件夹一起拷走，就能在新电脑上复盘以前的课

六、第三方软件
------------------------------------------
· 包里带的 Python、PyTorch 等第三方软件的许可证，汇总在 THIRD_PARTY_LICENSES.txt
