# M6 验收报告：简洁 / 进阶两种模式与动效（2026-10-29）

M6 的目标是两种界面模式和动效打磨（PLAN §6.7）：
- 简洁模式给低年级：动物头像、"图标 + 短词"、大按钮、星星评价、彩带；
- 进阶模式给高年级：步数、指标、AI 动作概率条、通信日志。

**验收**：两种模式各走查一遍。清单见 `docs/M6_WALKTHROUGH.md`。**已通过**：用户在浏览器里按清单走查完毕。期间对老师页的布局做了较多打磨，见 §5。

## 1. 模块

| 文件 | 职责 |
|---|---|
| `static/shared/ws.js` | `ANIMALS`（固定顺序的 24 个动物 emoji）、`agentAvatar(i)`（超过 24 个时加数字）；`checkVersion`（前端版本变了自动刷新） |
| `static/shared/grid-renderer.js` | 智能体支持 `emoji`（圆点里画动物，代替编号）、`badge`（老师页编号旁的小动物）、`shake`（被挡晃一下）、`arrived`（到达时旗子弹一下） |
| `static/shared/theme.css` | 晃动、弹跳、彩带、倒计时脉冲动画；字体栈补上三种彩色 emoji 字体 |
| `static/student/` | 简洁模式：动物、"你是 🐱"、"图标 + 短句"状态、彩带、星星结束页。进阶模式：揭晓卡片的 AI 概率条、"我的统计"。两种模式共用：被挡反馈、新一步闪框、倒计时最后 5 秒脉冲 |
| `static/screen/` | 简洁模式下，结束后的全图用动物；排行榜用 🏆 和星星 |
| `static/teacher/` | 编号旁加动物、座位下拉框写成"3 号 🐰"；布局打磨见 §5 |
| `classroom/core/round.py` | 立即揭晓的 `reveal` 消息带上 `ai_probs`，仍然只在结算之后才发 |

## 2. 关键口径（与用户确认）

- **动物头像**：用在学生页和投屏，老师页在编号旁加动物。只在简洁模式下使用；进阶模式三处都用编号。
- **不做音效**，只做视觉动效。
- **学生页的文字**：
  - 不用"通信 / 交换视野 / AI"这类词，改成"和队友说话 / 互相看看 / 电脑"；
  - **不单独放一个符号**，一律"图标 + 短词"，例如"👉 选一个方向""✅ 选好了 ↑""✋ 被挡住了，换个方向试试"。最初的版本只放图标，用户反馈"小朋友更不知道什么意思"，已经全部改掉。
- **星星**：全队都到 ★★★，自己到了 ★★☆，没到 ★☆☆。
- **AI 概率条**：在进阶模式、立即揭晓时，结算后才显示。"只给老师看"模式下学生页从头到尾不出现（不变式 8）。

## 3. 老师页布局（试用中逐步定下来）

| 布局 | 左栏 | 中间 | 右栏 |
|---|---|---|---|
| 课堂 | 规则（可折叠）+ 同学（占满剩余高度，单独滚动） | 地图 | 控制 + 叠放卡片（本步 / 本步通信 / 本局结果）+ 排行榜 |
| 地图工坊 | 工坊工具（这张地图 / 生成 / 编辑 / 地图库），贴顶、单独滚动 | 大画布（按窗口大小放大） | 无 |
| 复盘 | 每个智能体的对比表 / 本步通信 / 教学指标 / 导出，贴顶、单独滚动，两张表在卡片内滚动、表头固定 | 选课选局、地图、播放条 | 同课堂 |
| 全部（多组总览） | 隐去 | 所有组的缩略图排在一屏内 | 隐去；底部浮出一条控制栏 |

- 切换布局分两段，任何时候都不在动画中压窄内容：当前两侧卡片先滑出，然后换布局，新的侧边卡片再滑入。
- 右栏可以往右收起（"收起右栏 ▸"），让出宽度给中间和左栏；课堂和复盘都能用。
- 控制卡片下面的卡片可以"叠起"到控制卡片后面，每张只露出一条摘要；点任意一条就全部展开。
- 各栏的显隐用模板里的 `v-show` 控制，产生的是行内 `display:none`，不会被别的 CSS 规则覆盖。

## 4. 验收

- **自动化测试**：
  - `test_round.py`：立即揭晓时 `reveal` 带 `ai_probs`（5 维，和为 1），而且只在结算之后出现；"只给老师看"和"赛后复盘"模式下，学生收到的任何消息里都没有 `ai_probs`。
  - `test_server.py`：
    - 版本号随 welcome 和快照下发（`test_version_sent_for_auto_reload`）；
    - 禁止裸写状态类规则（`test_no_bare_state_class_rules`）；
    - 新增 `test_layout_columns_not_forced_visible`：老师页的布局模式类（`.overview` / `.sides-out` / `.ws-mode` / `.rv-mode` / `.no-right` / `.right-out`）不能被裸写成规则，栏目也不能被更高优先级的 `display` 规则强行显示。
- **前端检查**：node 语法检查，全部组件模板编译通过。
- **无头浏览器自检**：从这一轮起，布局改动都在 headless Chromium 里截图核对，并读出各栏宽度和滚动位置。临时服务开在单独端口，由机器人打一局造数据。
- **走查**：用户按清单在浏览器里走查两种模式，通过。

## 5. 试用中发现并修复的问题

| 现象 | 原因 | 修复 |
|---|---|---|
| 简洁模式只放符号，小朋友看不懂 | 一开始把文字全换成了图标 | 一律"图标 + 短词"，学生页去掉"通信"一类的词 |
| 规则卡片挡住同学列表 | 规则卡片太长 | 规则卡片可以折叠（0.5 s 过渡，收起后显示一行摘要）；同学列表在卡片内单独滚动 |
| 规则卡片收起时，同学卡片"先小后长" | 动画结束后才用 JS 重算同学卡片的高度 | 改为弹性布局，同学卡片每一帧都跟着变 |
| 控制卡片和本步卡片太占地方 | — | 叠放：本步卡片滑到控制卡片后面，只露出摘要；后来扩展到本步通信和本局结果，排行榜移到最下面 |
| 很高的卡片叠起时从控制卡片上方露头 | 往上拉的距离等于卡片自身高度 | 叠起时把高度封顶到控制卡片的高度 |
| "全部"总览过渡不顺：内容被挤成竖排、缩略图排两次版 | 两侧卡片在动画中被压窄 | 分两段过渡；按最终宽度一次排好缩略图，使一屏放下所有组；底部控制栏从下往上滑出 |
| 地图工坊沿用课堂的侧栏，没地方放工具 | — | 地图工坊有自己的布局：左边工具卡片，中间大画布；工具栏贴顶、单独滚动 |
| 切到课堂时多出地图工坊的工具栏、三栏错位 | `.layout > .col.side.left { display: flex }` 的优先级高于"按模式隐藏"的规则 | 删掉这条多余规则；后来各栏显隐都改成 `v-show` |
| 地图工坊整页被压成一列 | M3 遗留的 `.workshop { display: flex }` 和新加的同名布局模式类撞车 | 删掉遗留规则，模式类改名为 `ws-mode`，加测试守护 |
| 复盘页地图太小、表格放不下 | 复盘挤在课堂的中间栏里 | 复盘有自己的布局：左栏放对比表、教学指标和导出，右栏可以收起 |
| 服务重启后，学生标签页还在跑旧代码 | 只有 WS 重连，页面没有重新加载 | 前端版本号随 welcome 和快照下发，变了就自动刷新 |
| 状态初始化里有一行被误并进注释（排行榜等几项初值） | 编辑时注释吞掉了同一行后面的代码 | 恢复；页面原本靠收到数据时自动补上这几项，所以没有表现出来 |

## 6. 已知限制与后续

- 动物 emoji 在 Windows 上能否正常显示，要到 M7 的 Windows 实机上确认，见 `docs/M7_WALKTHROUGH.md`。
- 超过 24 个智能体时，动物会重复，后面加数字区分。
- 布局在窗口宽度小于 1200 像素时退化为单栏，没有专门优化平板竖屏。
