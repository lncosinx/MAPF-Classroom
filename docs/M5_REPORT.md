# M5 验收报告：复盘与导出（2026-10-28）

M5 的目标是复盘和导出：拖动进度条，看每个智能体每一步"学生 / 专家 / AI"的三列对比，并一键导出 pogema 原生 SVG 动画（PLAN §6.7），另外导出 CSV / JSONL（PLAN §6.5）。
**验收**：CSV / JSONL / SVG 都能打开，内容正确。**已通过**：自动化测试和临时服务上的实际下载核对都通过了，用户也在浏览器里手测通过。

## 1. 模块

| 文件 | 职责 |
|---|---|
| `classroom/storage/review.py` | 只读打开课堂记录（`file:...?mode=ro`）：`list_sessions` / `list_rounds` / `load_replay` / `student_replay`；教学指标；会话文件名校验（防路径穿越） |
| `classroom/storage/export.py` | `to_csv`（utf-8-sig）/ `to_jsonl` / `to_svg`（在 pogema 里重放并逐步核对，再导出动画） |
| `classroom/server/teacher_rpc.py` | `review.sessions` / `review.rounds` / `review.load`（读库放到线程里，不卡事件循环） |
| `classroom/server/app.py` | `GET /api/export/{课}/{局号或 all}.{csv|jsonl|svg}`，鉴权同老师 WS；学生 WS 的 `review` 消息 |
| `classroom/core/round.py` | 结束状态里加 `can_review` |
| `static/teacher/review.js` | 老师页"复盘"标签：选课 → 选局、进度条和播放、三列对比、AI 概率柱、教学指标、本步通信、导出 |
| `static/student/app.js` | 结束页的"🔍 复盘我的每一步"：自己的轨迹、三列对比、个人教学指标 |
| `static/shared/grid-renderer.js` | `stepKey`：箭头、连线、气泡等智能体补间走完再淡入 |

## 2. 三种导出

| 格式 | 内容 | 怎么打开 |
|---|---|---|
| CSV | 一行 = 某个智能体的一步。中文表头：课堂、局、组、步、智能体、控制方、昵称、座位号、动作（编号和中文名）、专家动作和来源、AI 动作、AI 五个方向的概率、与专家一致、与 AI 一致、思考毫秒、超时、改动次数、移动前后位置、到达 | Windows Excel 直接双击：文件带 BOM（utf-8-sig），中文不乱码 |
| JSONL | 每局先一行 `{"type":"round"}`（设置、地图、起终点、指标），再是 `{"type":"decision"}`（学生当时看到的视野、共享视野、AI 概率都已解析成对象），最后是 `{"type":"comm"}` | 研究用：`pandas.read_json(..., lines=True)` 或逐行 `json.loads` |
| SVG | 按记录的地图、起终点和联合动作，在 pogema 里重放这一局，再用 pogema 自带的 `render_animation` 导出 | 浏览器直接打开，会自动播放 |

SVG 在重放时**逐步核对位置**，包括终局位置，必须和记录一致，对不上就报错（`ReplayMismatch`），不会导出一段"看起来对"的动画。整节课的导出只支持 CSV / JSONL。下载前前端会提醒老师"含学生作答，请妥善保管"（不变式 14）。

## 3. 关键口径（与用户确认）

- **老师**可以复盘本节课和以前的课：在 `data/sessions/` 下按时间列出，用只读连接打开，不影响正在写库的本节课。只列出已经结束的局。
- **学生**在揭晓模式为"赛后复盘"或"立即揭晓"时，一局结束后能复盘**自己**的每一步。服务端只返回该学生控制的那些行和自己的轨迹，不含别人的轨迹；"只给老师看"模式下服务端直接拒绝。
- **教学指标**（PLAN §6.4）只统计学生控制的步：
  - 和专家一致率、和 AI 一致率；
  - 平均思考时间（超时的步不算）；
  - 等待次数；
  - 被挡次数：动作不是 wait 但位置没变；
  - 超时次数；
  - 通信次数：自己发起的视野请求和消息。
- **复盘画面**：箭头分"实际走法 / 专家 / AI"三种，可以分别开关；点表格某一行就只看那个智能体；自动播放每步 0.5 s（前 250 ms 是移动，然后箭头淡入）。

## 4. 验收

- **自动化测试**：`pytest` 共 157 项全部通过，其中 M5 新增 13 项：
  - `test_review.py` 12 项：
    - 列课 / 列局，5 种非法会话名都被拒绝；
    - 复盘帧数、位置、动作都和 `game.history` 逐步一致；
    - 教学指标手算对拍，AI 控制的步不统计；
    - 学生复盘只含本人的行；
    - CSV 带 BOM、中文表头、行数等于 N×T、概率和为 1；JSONL 三种类型都齐；
    - SVG 能解析；**篡改一步记录后重放报错**；
  - 端到端 1 项：
    - "只给老师看"时学生复盘被拒；赛后复盘模式下，结束前被拒、结束后只拿到自己的行；
    - 老师 RPC 列课 → 列局 → 复盘数据；
    - 导出时没带 key 返回 403；CSV / JSONL / SVG 的 content-type、中文文件名正确；`all.svg` 返回 400。
- **临时服务上实际下载核对**（单独端口，机器人打一局 doorway，40 步）：
  - CSV 200 行，与数据库一致；
  - JSONL 有 1 条局信息、200 条决策、59 条通信；
  - SVG 能解析（512×342，90 个元素）。
- **浏览器手测**：用户试用后通过。

## 5. 试用中发现并修复的问题

| 现象 | 原因 | 修复 |
|---|---|---|
| 复盘时每走一步，箭头先到新格子，智能体后到 | 智能体换位置有 250 ms 补间，而箭头是按新位置直接画的 | 地图组件新增 `stepKey`：箭头、连线、气泡随步号重建，等补间走完（250 ms）再淡入。老师实时观看和学生复盘也一并修好 |
| 自动播放时几乎看不到箭头 | 播放间隔 250 ms，和补间一样长 | 播放改为每步 0.5 s |

## 6. 已知限制与后续

- 复盘里的参照行（全 AI 队 / 专家队）只有终局成绩，没有逐步轨迹。
- 学生复盘只能看刚结束的这一局，以前的局只有老师能看。
- 导出的 SVG 是 pogema 默认样式，和课堂里的配色不完全一样。
