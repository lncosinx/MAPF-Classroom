# M6 走查清单：简洁 / 进阶两种模式

M6 的验收是"两种模式各走查一遍"。按下面的步骤在浏览器里走一遍，每一项打勾或者记下问题。

**准备**：服务重启或升级后，已打开的页面会自动刷新一次（版本号变了），不用手动刷新。
- 老师页 http://localhost:8000/teacher ；
- 3 个学生标签页 http://<本机局域网IP>:8000/ ，各起一个昵称加入；
- 另开一个窗口打开投屏页 http://localhost:8000/screen 。

## 一、简洁模式（低年级）

老师页：规则 → 界面选「简洁（低年级）」，地图「房门瓶颈」，视野 2 格，专家/AI 建议选「立即揭晓」，点「应用规则」，再点「开始」。

**学生页**
- [ ] 顶栏显示大号的"你是 🐱"（每人一个动物，各不相同）
- [ ] 地图上自己和视野里的同伴都是动物头像，不是数字；自己有脉冲光圈
- [ ] 自己的目标旗上带着同样的动物
- [ ] 方向键很大（每个约 88px），中间是"停"
- [ ] 倒计时旁是"图标 + 短句"：没选时"👉 选一个方向"，选了"✅ 选好了 ↑"；进度是"队友选好了 1/3"
- [ ] 每一步开始时，地图边框闪一下蓝光
- [ ] 倒计时最后 5 秒，圆环一跳一跳、数字变红
- [ ] 让两个同学挤同一个门：选了方向却没走动的那位，自己的头像会左右晃一下，屏幕中间弹出"✋ 被挡住了，换个方向试试"
- [ ] 走到终点那一步：旗子弹一下，满屏撒彩带，约 2 秒后消失
- [ ] "💬 和队友说话"卡片里的同伴用动物称呼；标签是短词（看不见、电脑、看到了、等回答）；按钮是"👀 互相看看"，消息按钮是图标 + 文字；**没有只放一个符号的地方**，也没有"通信 / 交换视野"这类词
- [ ] 结束页显示星星：全队都到 ★★★，自己到了 ★★☆，没到 ★☆☆；如果自己在终点，会再撒一次彩带
- [ ] 结束页没有"第几步""用时"之类的文字说明

**投屏页**
- [ ] 比赛中只有进度条，没有地图
- [ ] 某组结束后显示全图，图上是动物头像（和学生页对得上）
- [ ] 排行榜第 1 名是 🏆，成绩用星星表示

**老师页**
- [ ] 地图上仍是编号，每个圆点右上角有一个小动物
- [ ] 座位下拉框写成"3 号 🐰"，"本步"卡片里的同学条目也带动物
- [ ] 图例里有"编号旁的动物 = 学生页上看到的头像"

## 二、进阶模式（高年级）

老师页：界面改成「进阶（高年级）」，其他不变，点「应用规则」，再点「开始」。

**学生页**
- [ ] 顶栏是昵称和"第 n 步 / 最多 128 步"；地图上同伴显示编号，自己是红点（不显示动物）
- [ ] 倒计时旁是文字："请选择方向" / "已选 ↑"、"等待队友 1/3"；方向键下面有键盘提示
- [ ] 每一步结算后，揭晓卡片显示"你 / 专家 / AI"三列，下面是 **AI 对每个方向的把握**（5 条进度条，加起来约 100%）
- [ ] 侧边有"我的统计：走了 x 步 · 停了 y 次 · 被挡 z 次"，数字随每一步变化，和自己实际的走法一致
- [ ] 被挡住时头像晃一下，提示文字是"被挡住了，换个方向或等一等"
- [ ] 到达终点时旗子弹一下，**不撒彩带**
- [ ] 结束页是四个数字（到达比例、全队用时、总步数、全员到达），没有星星
- [ ] "💬 和队友说话"卡片里的同伴用"3 号"称呼；按钮是"👀 互相看看"，消息按钮有图标和文字；电脑控制的队友标"电脑"

**两种模式都要确认**
- [ ] 揭晓选「只给老师看」时，学生页**从头到尾**不出现专家 / AI 的任何信息，包括概率条
- [ ] 全图可见（视野选「全图可见」）时，以上动效照常
- [ ] 动物 emoji 在 Windows 老师机的浏览器里能正常显示（不是方框）。这一项留到 M7 在 Windows 实机上确认
