# M7 实机验收清单：Windows 绿色包

M7 的验收：**Windows 实机上双击启动，同一局域网的另一台电脑扫码加入，并玩完一局。**
按下面的步骤走一遍，每一项打勾或者记下问题。黑色窗口里有报错时，拍照或复制文字发回来。

**准备**：
- 一台 Win10 / 11（64 位）老师机；
- 至少一台同一 WiFi 下的学生设备（手机或电脑都行）；
- 把 `MAPF-Classroom-win64-<日期>.zip` 拷到老师机上。

## 一、解压与启动

- [ ] 右键 zip →「全部解压缩」到 `D:\MAPF-Classroom`（或其他纯英文路径），文件名都正常，没有乱码
- [ ] 文件夹里有 `start_classroom.bat`、`allow_firewall.bat`、`README.txt`、`python\`、`app\`
- [ ] 双击 `README.txt`，记事本里中文正常显示
- [ ] 双击 `start_classroom.bat`：弹出黑色窗口，先显示"正在加载 AI 模型……"，**30 秒内**显示学生加入地址和一个二维码
- [ ] 黑色窗口里的中文不是乱码；二维码是方的、能用手机扫出来
- [ ] 第一次运行弹出 Windows 防火墙提示：勾选「专用网络」，点「允许访问」
- [ ] 浏览器自动打开老师页 `http://localhost:8000/teacher`
- [ ] 记下：黑色窗口显示的学生地址是 ______；有没有"本机还有这些地址"这一行：有 / 没有

## 二、学生加入并玩完一局

- [ ] 学生设备扫老师页右上角的二维码（或手输地址），能打开学生页
  - 连不上时：右键 `allow_firewall.bat` →「以管理员身份运行」，再试一次，记下它的输出
- [ ] 学生起昵称加入；老师页的同学列表里出现这位同学
- [ ] 老师页「规则」里选一张地图，点「应用规则」，再点「开始」
- [ ] 学生页能看到地图和方向键，能走动；老师页地图同步更新，专家 / AI 箭头正常
- [ ] 一直玩到这一局结束（全员到达，或者到最大步数），老师页和学生页都显示结果
- [ ] **简洁模式**再开一局：学生页的**动物 emoji 显示正常**（不是方框或问号），老师页编号旁的小动物也正常（M6 留下的一项）
- [ ] 老师页右栏「本步」卡片里「专家」一项是 LaCAM，不是"简易专家"（说明 `lacam.dll` 加载成功）
- [ ] 每一步结算没有明显卡顿（记下大致感觉：流畅 / 等 1–2 秒 / 更久）

## 三、复盘与导出

- [ ] 切到「复盘」，能选到刚才那一局，拖动进度条、播放都正常
- [ ] 导出 CSV，用 **Excel 双击打开**，中文表头不乱码
- [ ] 导出 SVG，用浏览器打开能播放动画
- [ ] 关掉黑色窗口，课堂结束；`app\data\sessions\` 下有这节课的 `.sqlite` 文件

## 四、可选

- [ ] 关掉后再双击启动一次：不再弹防火墙提示，学生还能连上
- [ ] 开着一个课堂窗口时再双击一次：第二个窗口提示"8000 端口已被占用"，而不是一串英文报错
- [ ] 规则里把「AI 模型」换成「轻量 2.16M（老电脑）」，开一局能正常玩
- [ ] 解压到含中文的路径（例如桌面，用户名是中文时）试一次：窗口顶部出现"路径里有中文"的提醒；记下是否还能正常运行
